# Acessibilidade

## Propósito
Garantir que a Junta Observatory Platform é acessível a todos os utilizadores, incluindo pessoas com deficiência.

## Conformidade

| Norma | Nível |
|---|---|
| WCAG 2.1 | AA (mínimo), AAA (recomendado) |
| RGPD | Art. 25 — Protecção de dados desde a conceção |
| Lei de Acessibilidade | DL n.º 83/2018 |

## Práticas

| Prática | Implementação |
|---|---|
| **Contraste** | Rácio de contraste ≥ 4.5:1 |
| **Teclado** | Navegação completa por teclado |
| **Screen Reader** | ARIA labels, roles, landmarks |
| **Tamanho de Fonte** | Mínimo 16px, redimensionável |
| **Foco Visível** | Outline de foco em todos os elementos |
| **Idioma** | lang="pt" na página |
| **Imagens** | Alt text em todas as imagens |
| **Formulários** | Labels associados a campos |
