# Painel de Administração

## Propósito
Definir o painel de administração da Junta Observatory Platform.

## Módulos

| Módulo | Descrição |
|---|---|
| **Inquilinos** | Gestão de juntas clientes |
| **Utilizadores** | Gestão de contas e permissões |
| **Catálogo** | Configuração de serviços |
| **Workflows** | Definição de workflows |
| **Auditoria** | Logs de auditoria |
| **Configuração** | Parâmetros do sistema |
| **Monitorização** | Saúde e performance |
