# Formulários

## Propósito
Definir os padrões de formulários na Junta Observatory Platform.

## Padrões

| Padrão | Descrição |
|---|---|
| **Formulário Simples** | Campos verticais com label em cima |
| **Formulário em Passos** | Multi-step com progresso |
| **Formulário Condicional** | Campos que aparecem conforme respostas |
| **Formulário Dinâmico** | Gerado a partir de configuração |

## Validação

| Tipo | Comportamento |
|---|---|
| **Client-side** | Validação imediata ao preencher |
| **Server-side** | Validação adicional ao submeter |
| **Visual** | Campo verde (válido), vermelho (erro) |
