# Gestão de Processos — Oportunidades de IA

## Oportunidades

| Oportunidade | Descrição | Impacto |
|---|---|---|
| **Previsão de prazo** | Prever duração do processo com base em dados históricos | Planeamento |
| **Deteção de anomalias** | Identificar processos fora do padrão | Qualidade |
| **Recomendação de despacho** | Sugerir decisão com base em casos similares | Consistência |
| **Classificação de recursos** | Classificar probabilidade de recurso ser aceite | Eficiência |
| **Sumarização de processos** | Resumir processo longo para decisão | Produtividade |
