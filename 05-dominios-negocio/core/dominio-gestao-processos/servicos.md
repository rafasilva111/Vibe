# Gestão de Processos — Serviços

## Serviços

| Serviço | Descrição |
|---|---|
| **Criação de Processo** | Iniciar novo processo a partir de pedido |
| **Instrução Processual** | Gerir a recolha de elementos do processo |
| **Tramitação** | Movimentação do processo entre fases |
| **Despacho** | Submissão a decisão do dirigente |
| **Notificação** | Notificação electrónica de decisões |
| **Consulta** | Consulta de estado e andamento |
| **Arquivo** | Encerramento e arquivo do processo |
