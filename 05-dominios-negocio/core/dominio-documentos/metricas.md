# Documentos — Métricas

## Indicadores

| KPI | Descrição | Fonte |
|---|---|---|
| **Volume de documentos** | Nº de documentos armazenados | Armazenamento |
| **Taxa de OCR** | % de documentos com OCR bem-sucedido | Processamento |
| **Tempo de processamento** | Minutos desde upload até indexação | Workflow |
| **Espaço utilizado** | GB armazenados | S3 |
| **Documentos por tipo** | Distribuição por tipo de documento | Índice |
