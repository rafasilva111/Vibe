# Atendimento — Métricas

## Indicadores

| KPI | Descrição | Fonte |
|---|---|---|
| **Tempo médio de espera** | Minutos desde check-in até atendimento | Filas |
| **Tempo médio de atendimento** | Duração do atendimento | Interacções |
| **Taxa de absentismo** | % de agendamentos não comparecidos | Agendamentos |
| **Satisfação do cidadão** | Pontuação média de feedback | Feedback |
| **Volume de atendimentos** | Nº de atendimentos por dia/mês | Interacções |
| **Reclamações** | Nº de reclamações recebidas | Reclamações |
| **1ª chamada resolvida** | % resolvido no 1º contacto | Interacções |
