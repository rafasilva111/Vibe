# SIG

## Propósito
Integração com Sistemas de Informação Geográfica (SIG).

## Funcionalidades

| Funcionalidade | Descrição |
|---|---|
| **Consulta** | Visualização de dados geoespaciais |
| **Pesquisa** | Pesquisa por localização |
| **Camadas** | Sobreposição de mapas temáticos |
| **Marcação** | Marcação de pontos de interesse |

## Formatos

| Formato | Utilização |
|---|---|
| GeoJSON | Troca de dados com API |
| WMS | Mapas base |
| Shapefile | Exportação |
| KML | Google Earth |
