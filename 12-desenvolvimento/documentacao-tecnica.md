# Documentação Técnica

## Propósito
Definir a estratégia de documentação técnica.

## Formatos

| Tipo | Formato | Localização |
|---|---|---|
| **API** | OpenAPI 3.0 | docs/api/ |
| **Arquitetura** | Markdown + Mermaid | docs/ |
| **Código** | JavaDoc / JSDoc | No código |
| **Runbooks** | Markdown | docs/runbooks/ |
| **ADR** | Markdown (MADR) | docs/adr/ |

## Ferramentas

| Ferramenta | Utilização |
|---|---|
| **MkDocs** | Documentação estática |
| **Swagger UI** | Documentação interactiva da API |
| **PlantUML** | Diagramas (alternativa a Mermaid) |
