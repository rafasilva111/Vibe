# Normas de Código

## Propósito
Definir as normas de código para a equipa de desenvolvimento.

## Linguagens

| Linguagem | Norma | Linter |
|---|---|---|
| **Java** | Google Java Style | Checkstyle |
| **TypeScript** | Airbnb + Prettier | ESLint |
| **Python** | PEP 8 | Ruff |

## Práticas

| Prática | Descrição |
|---|---|
| **Formatação** | Automática (formatter) |
| **Nomenclatura** | camelCase (JS/TS), PascalCase (classes), snake_case (Python) |
| **Tamanho** | Máximo 200 linhas por ficheiro |
| **Comentários** | JSDoc / JavaDoc para APIs públicas |
| **Testes** | Cobertura mínima de 80% |
