# Localização

## Propósito
Definir a localização para Portugal.

## Configuração

| Aspecto | Valor |
|---|---|
| **Idioma padrão** | pt-PT |
| **Moeda** | EUR (€) |
| **Formato data** | DD/MM/AAAA |
| **Formato hora** | 24h |
| **Fuso horário** | Europe/Lisbon |
| **Números** | 1.234,56 (espaço milhar) |

## Conteúdo

- Vocabulário português europeu
| Termos jurídico-administrativos portugueses
| Formas de tratamento (Ex.mo, Ex.ma)
| Endereços postais conforme CTT
