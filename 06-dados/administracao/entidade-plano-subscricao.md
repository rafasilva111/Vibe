# Plano de Subscrição

## Descrição
Plano de subscrição da plataforma.

## Campos

| Campo | Tipo | Descrição |
|---|---|---|
| id | UUID (PK) | Identificador único |
| nome | String | Nome do plano |
| limites | JSON | Limites (utilizadores, processos, docs) |
| precos | JSON | Preços mensais/anuais |
| funcionalidades | JSON | Funcionalidades incluídas |
