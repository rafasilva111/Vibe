# Dashboards de Observação

## Propósito
Definir os dashboards de observação para monitorização técnica e operacional.

## Dashboards

| Dashboard | Público | Conteúdo |
|---|---|---|
| **Infraestrutura** | DevOps | CPU, memória, disco, rede |
| **Serviços** | DevOps | Latência, erros, throughput |
| **Base de Dados** | DBA | Conexões, IOPS, replicação |
| **Kafka** | DevOps | Lag, throughput, consumer groups |
| **SLA** | Gestão | Cumprimento de prazos |
| **Processos** | Operação | Volume, tempo médio, gargalos |
