# Convenções

## Propósito
Definir convenções adicionais de desenvolvimento.

## Commits

| Tipo | Descrição |
|---|---|
| `feat` | Nova funcionalidade |
| `fix` | Correção |
| `docs` | Documentação |
| `refactor` | Refactoring |
| `test` | Testes |
| `chore` | Manutenção |

Formato: `tipo(escopo): descrição` (ex: `feat(workflow): adicionar validação de prazos`)

## Pull Requests

| Requisito | Descrição |
|---|---|
| **Título** | Descritivo, com tipo |
| **Descrição** | O quê, porquê, como testar |
| **Tamanho** | Máximo 400 linhas |
| **Revisão** | Mínimo 1 approver |
| **Checklist** | Testes, lint, documentação |
