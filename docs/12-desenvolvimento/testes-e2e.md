# Testes E2E

## Propósito
Definir as práticas de testes end-to-end.

## Ferramenta

| Aspecto | Detalhe |
|---|---|
| **Framework** | Playwright / Cypress |
| **Browser** | Chromium (headless) |
| **Mobile** | Emulador mobile |
| **Ambiente** | Staging |

## Fluxos Críticos

| Fluxo | Descrição |
|---|---|
| **Registo** | Cidadão regista-se e submete pedido |
| **Atendimento** | Funcionário processa pedido |
| **Decisão** | Dirigente decide processo |
| **Notificação** | Cidadão recebe notificação |
| **Autenticação** | Login CMD, A-Gov, eIDAS |
