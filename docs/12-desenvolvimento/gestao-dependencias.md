# Gestão de Dependências

## Propósito
Definir a política de gestão de dependências.

## Política

| Aspecto | Prática |
|---|---|
| **Actualizações** | Dependências actualizadas trimestralmente |
| **Vulnerabilidades** | SCA em cada commit |
| **Licenças** | Verificação de licenças compatíveis |
| **Pin** | Versões fixas (não range) |
| **Lockfile** | Obrigatório (package-lock, poetry.lock) |

## Renovação

- Dependências de desenvolvimento actualizadas mensalmente
| Dependências de produção: mínimo review
| Alertas de segurança: actualização imediata
| Dependências obsoletas: plano de migração
