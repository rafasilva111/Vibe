Definir a estrutura da equipa do projeto.

| Perfil | Quantidade | Função |
|---|---|---|
| **Product Owner** | 1 | Visão, priorização, stakeholders |
| **Tech Lead** | 1 | Arquitetura, decisões técnicas |
| **Desenvolvedor Backend** | 3 | Microservices, APIs |
| **Desenvolvedor Frontend** | 2 | UI/UX, componentes |
| **QA** | 1 | Testes, qualidade |
| **DevOps** | 1 | CI/CD, infraestrutura |
| **UX Designer** | 1 | Design system, usabilidade |
| **DPO** | 0.5 | RGPD, privacidade |
