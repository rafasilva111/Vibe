# Riscos

## Propósito
Identificar os principais riscos do projeto.

## Matriz de Riscos

| Risco | Probabilidade | Impacto | Mitigação |
|---|---|---|---|
| **Adesão baixa** | Média | Alto | Programa de onboarding, casos de sucesso |
| **Complexidade legal** | Média | Alto | Jurista na equipa, revisão contínua |
| **Integrações externas** | Alta | Médio | APIs com fallback, simulação |
| **Performance** | Média | Alto | Testes de carga, arquitectura escalável |
| **Retenção equipa** | Média | Médio | Política de benefícios, formação |
| **Budget** | Baixa | Alto | MVP enxuto, financiamento faseado |
| **Segurança** | Média | Alto | Auditoria externa, bug bounty |

## Monitorização

- Review de riscos mensal
- Risk owner definido para cada risco
- Plano de contingência documentado
