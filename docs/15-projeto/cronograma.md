# Cronograma

## Propósito
Definir o cronograma macro do projeto.

## Fases

| Fase | Duração | Marcos |
|---|---|---|
| **Descoberta** | 2 meses | Documento de visão, ARDs |
| **MVP** | 6 meses | Atendimento + Licenciamento |
| **Expansão** | 6 meses | Restantes domínios core + plugins |
| **Otimização** | 3 meses | Performance, escalabilidade |
| **Manutenção** | Contínua | Suporte, evolução |

## Sprints

- Duração: 2 semanas
| Planning: 2h
| Daily: 15min
| Review: 1h
| Retrospetiva: 1h
