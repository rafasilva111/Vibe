# Previsão

## Propósito
Definir a abordagem de previsão de tendências na plataforma.

## Métodos

| Método | Aplicação |
|---|---|
| **Média Móvel** | Volume de processos a curto prazo |
| **Suavização Exponencial** | Tendências sazonais |
| **ARIMA** | Previsão de carga técnica |
| **Regressão Linear** | Crescimento de armazenamento |

## Objectivos

- Prever picos de carga para auto-scaling
- Antecipar necessidades de armazenamento
- Planear capacidade de equipa
- Identificar tendências sazonais
