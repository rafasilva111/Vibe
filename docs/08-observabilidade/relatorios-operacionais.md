# Relatórios Operacionais

## Propósito
Definir os relatórios operacionais gerados pela plataforma.

## Relatórios

| Relatório | Conteúdo | Periodicidade |
|---|---|---|
| **Resumo Diário** | Processos criados, concluídos, pendentes | Diário |
| **Desempenho Semanal** | Tempos médios, taxas de cumprimento | Semanal |
| **Análise Mensal** | Tendências, top serviços, gargalos | Mensal |
| **SLA** | Cumprimento de prazos por serviço | Mensal |
| **Capacidade** | Utilização de recursos, projecções | Trimestral |

## Formato

- PDF para distribuição
- Exportável para Excel para análise
- Envio automático por email para destinatários configurados
