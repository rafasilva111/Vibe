# Plataforma — Conhecimento

## Propósito

Gerir a base de conhecimento da Junta Observatory Platform, centralizando documentação legal, procedimentos internos, FAQs e guias de utilização.

## Responsabilidades

- Armazenar e gerir artigos da base de conhecimento
- Suportar pesquisa full-text
- Versionar artigos
- Controlar acessos por perfil

## Descrição Detalhada

### Categorias

| Categoria | Conteúdo | Público |
|---|---|---|
| **Legislação** | Leis, decretos, portarias aplicáveis | Público |
| **Procedimentos** | Passos para cada serviço | Funcionários |
| **FAQs** | Perguntas frequentes | Cidadão |
| **Guias** | Manuais de utilização da plataforma | Cidadão + Funcionário |
| **Pareceres** | Pareceres jurídicos internos | Funcionários (restrito) |

### Integração com Assistente AI

A base de conhecimento alimenta o sistema de RAG do assistente AI, permitindo respostas contextuais baseadas na documentação.
