# Plugins — Domínios de Negócio

## Propósito

Os domínios plugin representam áreas de negócio opcionais que podem ser activadas conforme as competências e necessidades de cada junta de freguesia.

## Domínios

| Domínio | Propósito |
|---|---|
| [Espaços](dominio-espacos/index.md) | Gestão de espaços municipais e multiusos |
| [Atividades](dominio-atividades/index.md) | Licenciamento e gestão de actividades |
| [Ação Social](dominio-acao-social/index.md) | Apoio social e acompanhamento |
| [Obras](dominio-obras/index.md) | Obras municipais e conservação |
| [Ambiente](dominio-ambiente/index.md) | Gestão ambiental e resíduos |
| [Proteção Civil](dominio-protecao-civil/index.md) | Protecção civil e emergência |
| [Feiras e Mercados](dominio-feiras-mercados/index.md) | Gestão de feiras e mercados |
| [Cemitérios](dominio-cemiterios/index.md) | Gestão cemiterial |
| [Financeiro](dominio-financeiro/index.md) | Gestão financeira e taxas |
| [Recursos Humanos](dominio-recursos-humanos/index.md) | Gestão de RH |
| [Protocolo e Comunicação](dominio-protocolo-comunicacao/index.md) | Comunicação e relações públicas |

## Estrutura

Cada domínio plugin segue a mesma estrutura dos domínios core, com os ficheiros: `index.md`, `processos.md`, `servicos.md`, `tarefas.md`, `fluxos-de-trabalho.md`, `documentos.md`, `eventos.md`, `automacoes.md`, `metricas.md`, `oportunidades-ai.md`, `pontos-de-decisao.md`.
