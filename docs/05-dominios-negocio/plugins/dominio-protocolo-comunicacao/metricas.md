# Protocolo e Comunicação — Métricas

## Indicadores

| KPI | Descrição |
|---|---|
| **Eventos realizados** | Nº de eventos por trimestre |
| **Comunicados emitidos** | Nº de comunicados de imprensa |
| **Presença mediática** | Menções na comunicação social |
| **Engagement redes sociais** | Interações, seguidores |
| **Satisfação de eventos** | Feedback dos participantes |
