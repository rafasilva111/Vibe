# Obras — Serviços

## Serviços

| Serviço | Descrição |
|---|---|
| **Conservação de Arruamentos** | Reparação de pavimentos |
| **Conservação de Espaços Verdes** | Manutenção de jardins e parques |

| **Pequenas Reparações** | Reparações em mobiliário urbano |
| **Sinalização** | Colocação e manutenção de sinalização |
