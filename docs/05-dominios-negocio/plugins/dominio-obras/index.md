# Domínio — Obras

## Propósito

Gerir as obras municipais realizadas pela junta de freguesia, incluindo conservação, reparação e pequenas intervenções no espaço público.

## Entidades Principais

| Entidade | Descrição |
|---|---|
| **Obra** | Intervenção municipal (conservação, reparação) |
| **ProjetoObra** | Projecto técnico associado |
| **Empreiteiro** | Empresa contratada para execução |
| **VistoriaObra** | Vistoria de acompanhamento |
| **Orcamento** | Orçamento da intervenção |

## Regras de Negócio

- Obras < 10.000€: dispensa de concurso público
- Obras ≥ 10.000€: procedimento concursal
- Vistoria obrigatória após conclusão
- Garantia mínima de 5 anos para obras executadas
