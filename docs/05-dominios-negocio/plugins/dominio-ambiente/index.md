# Domínio — Ambiente

## Propósito

Gerir as competências ambientais da junta de freguesia, incluindo resíduos, limpeza urbana, espaços verdes e sensibilização ambiental.

## Entidades Principais

| Entidade | Descrição |
|---|---|
| **Residuo** | Gestão de resíduos e recolha |
| **EspacoVerde** | Jardim, parque ou espaço verde |
| **LimpezaUrbana** | Operação de limpeza |
| **DenunciaAmbiental** | Denúncia de infração ambiental |
| **Campanha** | Campanha de sensibilização |

## Regras de Negócio

- Recolha de resíduos volumosos: agendamento obrigatório
- Denúncias ambientais: resposta em 10 dias úteis
- Manutenção de espaços verdes: calendário sazonal
- Limpeza urbana: frequência conforme zona (centro vs periferia)
