# Domínio — Financeiro

## Propósito

Gerir as operações financeiras da junta de freguesia, incluindo contabilidade orçamental, gestão de tesouraria, facturação, cobrança de taxas e prestação de contas.

## Entidades Principais

| Entidade | Descrição |
|---|---|
| **Orcamento** | Orçamento anual da junta |
| **RubricaOrcamental** | Rubrica do orçamento |
| **Compromisso** | Compromisso financeiro assumido |
| **Fatura** | Fatura emitida ou recebida |
| **Receita** | Receita cobrada (taxas, multas) |
| **Despesa** | Despesa realizada |
| **Pagamento** | Pagamento efectuado |
| **Conta** | Conta bancária da junta |

## Regras de Negócio

- Execução orçamental: obrigatório respeito pelas rubricas aprovadas
- Compromissos: autorização prévia obrigatória para > 5.000€
- Cobrança coerciva: dívidas > 90 dias enviadas para execução fiscal
- Prestação de contas: envio ao tribunal de contas conforme Lei de Enquadramento Orçamental
- Fundo de maneio: saldo mínimo de 10% do orçamento anual
