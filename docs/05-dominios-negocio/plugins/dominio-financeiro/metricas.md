# Financeiro — Métricas

## Indicadores

| KPI | Descrição |
|---|---|
| **Execução orçamental** | % do orçamento executado |
| **Prazo médio de pagamento** | Dias até pagamento a fornecedor |
| **Prazo médio de cobrança** | Dias até recebimento |
| **Taxa de cobrança** | % de receitas cobradas vs emitidas |
| **Desvio orçamental** | Diferença entre previsto e real |
| **Dívida total** | Valor total em dívida |
