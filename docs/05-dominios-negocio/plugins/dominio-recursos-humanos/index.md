# Domínio — Recursos Humanos

## Propósito

Gerir os recursos humanos da junta de freguesia, incluindo recrutamento, férias, ausências, avaliação de desempenho, formação e processamento salarial.

## Entidades Principais

| Entidade | Descrição |
|---|---|
| **Funcionario** | Colaborador da junta |
| **Departamento** | Departamento ou pelouro |
| **Contrato** | Contrato de trabalho |
| **Ausencia** | Férias, licenças, faltas |
| **Avaliacao** | Avaliação de desempenho (SIADAP) |
| **Formacao** | Acção de formação |
| **ProcessamentoSalarial** | Processamento de vencimentos |

## Regras de Negócio

- Contratação: concurso público obrigatório (salvo excepções legais)
- Férias: 22 dias úteis por ano, marcação até 30 de Abril
- Avaliação de desempenho: conforme SIADAP (anual)
- Formação: mínimo 40h/ano por trabalhador (se aplicável)
- Processamento salarial: processado até ao dia 25 de cada mês
