# Recursos Humanos — Pontos de Decisão

## Decisões

| Ponto | Decisor | Critérios |
|---|---|---|
| **Aprovar recrutamento?** | Presidente | Necessidade, orçamento |
| **Selecionar candidato?** | Júri | Classificação final |
| **Aprovar férias?** | Chefe de Departamento | Planeamento, cobertura |
| **Avaliação final?** | Chefe de Departamento + Avaliado | SIADAP, contraditório |
| **Promover?** | Presidente | Avaliação, antiguidade |
