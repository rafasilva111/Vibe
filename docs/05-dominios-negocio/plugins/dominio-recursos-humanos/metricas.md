# Recursos Humanos — Métricas

## Indicadores

| KPI | Descrição |
|---|---|
| **Efetivo** | Nº total de funcionários |
| **Taxa de absentismo** | % de dias não trabalhados |
| **Horas de formação** | Média de horas de formação por funcionário |
| **Rotatividade** | % de saídas no período |
| **Avaliações** | Distribuição de classificações SIADAP |
| **Custo com pessoal** | % do orçamento em RH |
