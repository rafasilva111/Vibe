# Domínio — Ação Social

## Propósito

Gerir o apoio social prestado pela junta de freguesia, incluindo acompanhamento de famílias, atribuição de apoios e parcerias com instituições.

## Entidades Principais

| Entidade | Descrição |
|---|---|
| **Familia** | Família acompanhada pelos serviços sociais |
| **ProcessoSocial** | Processo de acompanhamento social |
| **Apoio** | Atribuição de apoio (monetário, bens, serviços) |
| **Instituicao** | Instituição parceira (IPSS, associação) |
| **Visita** | Visita domiciliária do técnico |

## Regras de Negócio

- Apoio social requer avaliação técnica prévia
- Apoios monetários têm tecto máximo definido anualmente
- Visitas domiciliárias: mínimo 1 por trimestre para famílias activas
- Dados de acção social são confidenciais (acesso restrito)
