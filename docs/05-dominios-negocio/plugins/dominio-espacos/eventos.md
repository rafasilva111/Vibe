# Espaços — Eventos

## Eventos

| Evento | Significado |
|---|---|
| `espaco.reserva.solicitada` | Pedido de reserva submetido |
| `espaco.reserva.confirmada` | Reserva confirmada |
| `espaco.reserva.cancelada` | Reserva cancelada |
| `espaco.ocupacao.iniciada` | Ocupação do espaço iniciada |
| `espaco.ocupacao.concluida` | Ocupação terminada |
| `espaco.caucao.devolvida` | Caução devolvida ao requerente |
