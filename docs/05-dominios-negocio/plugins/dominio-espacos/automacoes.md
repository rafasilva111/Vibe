# Espaços — Automações

## Regras

| Regra | Condição | Acção |
|---|---|---|
| **Verificação de disponibilidade** | Pedido recebido | Consultar calendário |
| **Confirmação automática** | Sem conflitos + caução paga | Confirmar reserva |
| **Lembrete** | 24h antes da ocupação | Notificar requerente |
| **Vistoria automática** | Ocupação concluída | Criar tarefa de vistoria |
