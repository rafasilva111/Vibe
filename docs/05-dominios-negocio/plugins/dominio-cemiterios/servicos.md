# Cemitérios — Serviços

## Serviços

| Serviço | Descrição |
|---|---|
| **Inumação** | Sepultamento em campa ou jazigo |
| **Exumação** | Remoção de restos mortais |
| **Concessão** | Atribuição de jazigo/capela |
| **Transmissão** | Transmissão de titularidade |
| **Manutenção** | Conservação do cemitério |
| **Obras em Jazigos** | Licenciamento de obras |
