# Atestados — Eventos

## Eventos de Domínio

| Evento | Significado | Consumidores |
|---|---|---|
| `atestado.pedido.criado` | Pedido de atestado submetido | Workflow, Notificações |
| `atestado.emitido` | Atestado foi emitido | Documentos, Notificações |
| `atestado.assinado` | Atestado foi assinado digitalmente | Documentos |
| `atestado.entregue` | Atestado entregue ao cidadão | Casos |
| `atestado.recusado` | Pedido recusado (não residente) | Notificações |
