# Licenciamento — Pontos de Decisão

## Decisões

| Ponto | Decisor | Critérios |
|---|---|---|
| **Obra menor vs maior** | Sistema + Técnico | Dimensão, tipo, localização |
| **Documentação suficiente?** | Técnico | Checklist completo |
| **Parecer técnico** | Técnico especialista | Conformidade legal e técnica |
| **Licenciar?** | Dirigente (delegação) | Mérito e legalidade |
| **Vistoria necessária?** | Sistema / Técnico | Tipo de licença, risco |
| **Renovar?** | Técnico | Condições mantêm-se? |
