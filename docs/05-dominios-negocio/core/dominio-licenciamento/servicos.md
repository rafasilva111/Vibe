# Licenciamento — Serviços

## Serviços

| Serviço | Descrição | Delegação |
|---|---|---|
| **Licença de Obra Menor** | Obras de conservação e reparação | Junta |
| **Licença de Obra Maior** | Obras de construção e ampliação | Câmara (parecer) |
| **Ocupação de Via Pública** | Esplanadas, toldos, contentores | Junta |
| **Actividades Eventuais** | Feiras, arraiais, eventos | Junta |
| **Publicidade** | Cartazes, letreiros, toldos | Junta |
| **Licença de Arruamentos** | Cortes de trânsito | Câmara |
