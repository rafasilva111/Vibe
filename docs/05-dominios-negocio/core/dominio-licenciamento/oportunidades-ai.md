# Licenciamento — Oportunidades de IA

## Oportunidades

| Oportunidade | Descrição | Impacto |
|---|---|---|
| **Análise automática de projectos** | Validar conformidade de projectos com regulamento | Eficiência |

| **Deteção de irregularidades** | Identificar padrões de incumprimento | Fiscalização |
| **Previsão de risco** | Avaliar risco de infração com base em histórico | Prevenção |
