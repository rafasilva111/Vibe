# Domínio — Atendimento

## Propósito

Gerir o atendimento ao cidadão nos canais presencial, telefónico e digital, incluindo agendamento, triagem, encaminhamento e registo de interacções.

## Entidades Principais

| Entidade | Descrição |
|---|---|
| **PedidoAtendimento** | Pedido de atendimento (presencial ou remoto) |
| **Agendamento** | Marcação para atendimento presencial |
| **Interacção** | Registo de cada interacção com o cidadão |
| **FilaEspera** | Gestão de filas de atendimento presencial |
| **Senha** | Senha de atendimento (presencial) |
| **Feedback** | Avaliação do atendimento pelo cidadão |

## Regras de Negócio

- Atendimento presencial prioritário: maiores de 65 anos, grávidas, pessoas com deficiência
- Agendamento obrigatório para serviços complexos (licenciamento)
- Resposta inicial a pedidos digitais em até 5 dias úteis
- Registo de todas as interacções no processo do cidadão
