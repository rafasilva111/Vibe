# Gestão de Processos — Processos

## Processos

| Processo | Descrição |
|---|---|
| **Abertura de Processo** | Criação de novo processo administrativo |
| **Instrução** | Recolha de documentos, pareceres e informações |
| **Decisão** | Despacho favorável, desfavorável ou condicionado |
| **Notificação** | Comunicação da decisão ao cidadão |
| **Arquivo** | Encerramento e arquivo do processo |
| **Reabertura** | Reabertura de processo arquivado |
