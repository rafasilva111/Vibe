# Gestão de Processos — Automações

## Regras de Automação

| Regra | Condição | Acção |
|---|---|---|
| **Triagem automática** | Caso criado | Classificar por tipo e serviço |
| **Atribuição automática** | Instrução necessária | Atribuir ao técnico com menos carga |
| **Cálculo de prazo** | Caso criado / transicionado | Calcular prazo (dias úteis) |
| **Alerta de prazo** | 75% do prazo decorrido | Notificar responsável |
| **Incumprimento** | Prazo excedido | Notificar superior hierárquico |
| **Arquivo automático** | Concluído há 30 dias | Arquivar processo |
