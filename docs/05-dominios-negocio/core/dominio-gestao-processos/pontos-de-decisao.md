# Gestão de Processos — Pontos de Decisão

## Decisões

| Ponto | Decisor | Critérios |
|---|---|---|
| **Triagem** | Sistema | Tipo de serviço, documentos apresentados |
| **Instrução completa?** | Técnico | Todos os elementos recolhidos |
| **Parecer favorável?** | Técnico especialista | Análise técnica e legal |
| **Decisão** | Dirigente | Mérito, legalidade, conveniência |
| **Recurso** | Dirigente superior | Fundamentação do recurso |
| **Arquivo** | Sistema | Processo concluído + 30 dias |
