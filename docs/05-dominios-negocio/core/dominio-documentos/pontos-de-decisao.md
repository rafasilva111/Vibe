# Documentos — Pontos de Decisão

## Decisões

| Ponto | Decisor | Critérios |
|---|---|---|
| **Documento aceite?** | Sistema | Tipo, tamanho, vírus |
| **Classificação correcta?** | Sistema (IA) + validação humana | Confiança do modelo ≥ 90% |
| **Assinatura válida?** | Sistema | Certificado válido, não revogado |
| **Partilha autorizada?** | Proprietário do documento | Consentimento explícito |
| **Eliminar?** | Sistema | Política de retenção cumprida |
