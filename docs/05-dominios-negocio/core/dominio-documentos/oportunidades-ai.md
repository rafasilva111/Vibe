# Documentos — Oportunidades de IA

## Oportunidades

| Oportunidade | Descrição | Impacto |
|---|---|---|
| **Classificação inteligente** | Classificar documentos por tipo e conteúdo | Precisão |
| **Extracção de entidades** | Extrair entidades (nomes, NIFs, datas) de documentos | Automação |
| **Deteção de anomalias** | Detetar documentos fraudulentos ou inconsistentes | Segurança |
| **Sumarização** | Resumir documentos longos para decisão | Produtividade |
| **OCR avançado** | Reconhecimento de escrita manual | Acessibilidade |
