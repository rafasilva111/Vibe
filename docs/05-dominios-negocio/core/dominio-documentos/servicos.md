# Documentos — Serviços

## Serviços

| Serviço | Descrição |
|---|---|
| **Armazenamento** | Guardar documentos com encriptação e redundância |
| **Processamento** | OCR, classificação automática, extração de metadados |
| **Pesquisa** | Pesquisa full-text sobre documentos indexados |
| **Assinatura** | Assinatura digital qualificada |
| **Versionamento** | Gestão de versões de documentos |
| **Partilha** | Partilha segura com terceiros |
