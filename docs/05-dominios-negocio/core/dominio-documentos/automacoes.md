# Documentos — Automações

## Regras de Automação

| Regra | Condição | Acção |
|---|---|---|
| **Classificação automática** | Documento carregado | Classificar por tipo (IA) |
| **OCR automático** | Documento é imagem/PDF | Aplicar OCR |
| **Extração de metadados** | Documento processado | Extrair data, nº documento, entidade |
| **Notificação de assinatura** | Documento aguarda assinatura | Notificar responsável |
| **Eliminação programada** | Data de retenção expirada | Soft delete + notificar |
