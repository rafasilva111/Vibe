# Padrões de Interação

## Propósito
Definir os padrões de interação para a interface da Junta Observatory Platform.

## Padrões

| Padrão | Descrição |
|---|---|
| **Click** | Acção principal (botões, links) |
| **Double-click** | Edição inline de campos |
| **Drag & Drop** | Reordenar, anexar ficheiros |
| **Hover** | Tooltips, acções secundárias |
| **Right-click** | Menu contextual (futuro) |

## Feedback

| Acção | Feedback |
|---|---|
| Submeter formulário | Loading state + toast de confirmação |
| Erro de validação | Campo vermelho + mensagem de erro |
| Acção concluída | Toast de sucesso (3s) |
| Acção destrutiva | Modal de confirmação |
| Upload de ficheiro | Barra de progresso |
