# Construtor de Workflows

## Propósito
Definir a interface visual para construção de workflows na Junta Observatory Platform.

## Funcionalidades

| Funcionalidade | Descrição |
|---|---|
| **Canvas** | Área de desenho drag & drop |
| **Paleta** | Lista de elementos disponíveis |
| **Propriedades** | Painel de configuração do elemento |
| **Validação** | Verificação de consistência |
| **Simulação** | Teste do workflow em ambiente controlado |
| **Publicação** | Publicação de nova versão |

## Elementos

| Elemento | Descrição |
|---|---|
| **Estado** | Estado do processo |
| **Transição** | Ligação entre estados |
| **Tarefa** | Tarefa manual a executar |
| **Decisão** | Ponto de decisão (sim/não) |
| **Automação** | Acção automática |
| **Temporizador** | Espera/atraso |
