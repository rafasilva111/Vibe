# Gestão de Perfis

## Propósito
Definir a interface de gestão de perfis e permissões na Junta Observatory Platform.

## Funcionalidades

| Funcionalidade | Descrição |
|---|---|
| **Lista de Perfis** | Tabela com perfis e descrições |
| **Editor de Perfil** | Atribuição de permissões por módulo |
| **Matriz de Permissões** | Grid perfil × permissão |
| **Histórico** | Registo de alterações de permissões |

## Interface

- Checkboxes agrupados por módulo
- Selecção em massa (select all / none)
- Filtro por módulo
- Botão de guardar com confirmação
- Indicação visual de permissões conflituantes
