# Painel Principal

## Propósito
Definir o dashboard principal da Junta Observatory Platform para cada perfil de utilizador.

## Cidadão

| Widget | Descrição |
|---|---|
| **Meus Processos** | Lista dos processos activos com estado |
| **Próximos Prazos** | Alertas de prazos a expirar |
| **Serviços Rápidos** | Acesso rápido aos serviços mais utilizados |
| **Notificações** | Últimas notificações |

## Funcionário

| Widget | Descrição |
|---|---|
| **Tarefas Pendentes** | Lista de tarefas atribuídas |
| **Processos em Curso** | Processos que está a instruir |
| **Prazos Críticos** | Alertas de prazos próximos do limite |
| **Métricas Rápidas** | Processos concluídos hoje, pendentes |
