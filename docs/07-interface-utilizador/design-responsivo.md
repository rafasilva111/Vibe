# Design Responsivo

## Propósito
Definir a estratégia de design responsivo da Junta Observatory Platform.

## Breakpoints

| Nome | Largura | Alvo |
|---|---|---|
| **Mobile** | < 768px | Smartphones |
| **Tablet** | 768px - 1024px | Tablets |
| **Desktop** | 1024px - 1440px | Monitores |
| **Wide** | > 1440px | Monitores largos |

## Abordagem

| Elemento | Comportamento |
|---|---|
| **Layout** | Grid flexível (CSS Grid + Flexbox) |
| **Navegação** | Hamburger menu em mobile |
| **Tabelas** | Horizontal scroll ou cards em mobile |
| **Formulários** | Coluna única em mobile |
| **Imagens** | Max-width 100%, height auto |
| **Tipografia** | Escalável (rem) |
