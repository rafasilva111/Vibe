# Notificações

## Propósito
Definir a interface de notificações na Junta Observatory Platform.

## Componentes

| Componente | Descrição |
|---|---|
| **Ícone de Sino** | Indicador de notificações não lidas |
| **Dropdown** | Lista das últimas notificações |
| **Caixa Postal** | Página completa de notificações |
| **Toast** | Notificação temporária no canto |
| **Banner** | Notificação importante no topo |

## Tipos

| Tipo | Cor | Comportamento |
|---|---|---|
| **Sucesso** | Verde | Toast |
| **Alerta** | Amarelo | Toast + Sino |
| **Crítico** | Vermelho | Banner + Sino + Email |
| **Informativo** | Azul | Toast |
