# Visualização de Processos

## Propósito
Definir como os processos são visualizados na interface.

## Componentes

| Componente | Descrição |
|---|---|
| **Linha Temporal** | Timeline de eventos do processo |
| **Diagrama de Estado** | Estado actual e transições possíveis |
| **Detalhe do Processo** | Informação completa do processo |
| **Documentos** | Lista de documentos associados |
| **Tarefas** | Tarefas pendentes e concluídas |
| **Mapa do Workflow** | Visualização gráfica do workflow |
