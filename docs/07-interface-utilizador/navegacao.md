# Navegação

## Propósito
Definir a estrutura de navegação da Junta Observatory Platform.

## Estrutura

| Nível | Descrição |
|---|---|
| **Global** | Menu principal (Dashboard, Processos, Serviços, Admin) |
| **Secundário** | Sub-navegação por módulo |
| **Contextual** | Acções relacionadas com o conteúdo actual |
| **Breadcrumbs** | Indicação da localização actual |

## Menus por Perfil

| Perfil | Menu Principal |
|---|---|
| **Cidadão** | Dashboard, Meus Processos, Serviços, Perfil |
| **Funcionário** | Dashboard, Processos, Tarefas, Documentos |
| **Dirigente** | Dashboard, Processos, Relatórios, Equipa |
| **Administrador** | Dashboard, Configuração, Utilizadores, Logs |
