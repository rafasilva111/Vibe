# Sistema de Design

## Propósito
Definir o sistema de design da Junta Observatory Platform, incluindo cores, tipografia, espaçamento e componentes base.

## Tokens de Design

| Token | Valor | Utilização |
|---|---|---|
| `--color-primary` | #005CA0 | Acções principais, links |
| `--color-secondary` | #008080 | Destaques secundários |
| `--color-success` | #28A745 | Confirmações, sucesso |
| `--color-warning` | #FFC107 | Alertas, avisos |
| `--color-danger` | #DC3545 | Erros, eliminações |
| `--color-bg` | #FFFFFF | Fundo principal |
| `--color-text` | #212529 | Texto principal |
| `--font-family` | Inter, sans-serif | Tipografia principal |
| `--radius-sm` | 4px | Cantos pequenos |
| `--radius-md` | 8px | Cantos médios |

## Componentes Base

- Botões (primário, secundário, outline, ghost)
- Campos de formulário (input, select, checkbox, radio)
- Tabelas e listas
- Modais e diálogos
- Notificações (toast, banner)
- Navegação (menu, tabs, breadcrumbs)
- Cartões e painéis
- Indicadores de progresso
- Ícones (Lucide)
