# Acessibilidade Digital

## Propósito
Garantir a conformidade com normas de acessibilidade digital.

## Normas

| Norma | Nível |
|---|---|
| **WCAG 2.1** | AA (mínimo) |
| **DL n.º 83/2018** | Acessibilidade sítios web |
| **EN 301 549** | Norma europeia |

## Requisitos

| Requisito | Implementação |
|---|---|
| **Contraste** | ≥ 4.5:1 texto normal |
| **Teclado** | Toda a funcionalidade acessível por teclado |
| **Screen Reader** | ARIA labels, roles semânticas |
| **Redimensionamento** | Até 200% sem perda |
| **Foco** | Foco visível em todos os elementos |
| **Formulários** | Labels associados, mensagens de erro |
