# Privacidade

## Propósito
Definir as políticas de privacidade da Junta Observatory Platform.

## Princípios

| Princípio | Descrição |
|---|---|
| **Minimização** | Apenas dados necessários para o serviço |
| **Consentimento** | Recolha com consentimento explícito |
| **Transparência** | Informação clara sobre tratamento |
| **Segurança** | Medidas técnicas e organizativas |
| **Direitos** | Facilitação dos direitos do titular |

## Dados Pessoais

| Categoria | Dados | Retenção |
|---|---|---|
| **Identificação** | Nome, NIF, CC, CMD | 10 anos |
| **Contacto** | Email, telefone, morada | 10 anos |
| **Processuais** | Documentos, despachos | 10 anos |
| **Sociais** | Rendimentos, composição familiar | 5 anos |
| **Autenticação** | Logs de acesso, IP | 2 anos |
