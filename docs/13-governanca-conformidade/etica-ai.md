# Ética em IA

## Propósito
Definir os princípios éticos para IA na plataforma.

## Compromissos

| Compromisso | Descrição |
|---|---|
| **Transparência** | Utilizador informado quando interage com IA |
| **Não discriminação** | Modelos auditados para viés |
| **Supervisão humana** | Decisões críticas revistas por humano |
| **Privacidade** | Dados pessoais não usados para treino |
| **Responsabilidade** | Plataforma responsável por outputs de IA |

## Vedações

- IA não toma decisões finais sobre direitos legais
- IA não discrimina com base em raça, género, religião
| IA não armazena dados pessoais para treino
| IA não partilha dados com terceiros não autorizados
