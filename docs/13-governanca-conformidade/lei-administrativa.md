# Lei Administrativa

## Propósito
Mapear a conformidade com a lei administrativa portuguesa.

## Legislação Aplicável

| Lei | Descrição | Impacto |
|---|---|---|
| **CPA** | Código do Procedimento Administrativo | Prazos, audiência prévia, notificações |
| **RJAL** | Regime Jurídico das Autarquias Locais | Competências das juntas |
| **Lei Geral do Trabalho** | Código do Trabalho | RH, férias, faltas |
| **Lei do Licenciamento** | RJUE | Licenças de obra |
| **Lei das Taxas** | RGTAL | Taxas das autarquias |
| **Lei do Direito de Resposta** | — | Reclamações e recursos |
