# Template Mensagem

## Descrição
Template de mensagem usado em comunicação multi-canal.

## Campos

| Campo | Tipo | Descrição |
|---|---|---|
| id | UUID (PK) | Identificador único |
| codigo | String | Código único do template |
| conteudo | Text | Conteúdo com placeholders |
| idioma | String | Idioma (pt-PT) |
| versao | String | Versão |
