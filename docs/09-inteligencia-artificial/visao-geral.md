# IA — Visão Geral

## Propósito
Apresentar a visão geral da estratégia de Inteligência Artificial na Junta Observatory Platform.

## Capacidades

| Capacidade | Descrição |
|---|---|
| **Assistente Virtual** | Chatbot para cidadãos e funcionários |
| **Sumarização** | Resumo automático de processos |
| **Classificação** | Classificação de pedidos e documentos |
| **Recomendação** | Sugestão de acções e decisões |
| **Extracção** | Extracção de dados de documentos |
| **Previsão** | Análise preditiva de tendências |

## Stack

| Componente | Tecnologia |
|---|---|
| **LLM** | GPT-4 / Claude / Modelo aberto (futuro) |
| **RAG** | LangChain + Vector Store (Pinecone) |
| **OCR** | Tesseract + Azure Form Recognizer |
| **ML** | Python + scikit-learn / PyTorch |
| **Embeddings** | OpenAI / Sentence Transformers |
