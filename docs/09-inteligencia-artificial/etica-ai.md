# Ética em IA

## Propósito
Definir os princípios éticos para utilização de IA na plataforma.

## Princípios

| Princípio | Descrição |
|---|---|
| **Transparência** | Utilizador sabe quando interage com IA |
| **Equidade** | Modelos sem viés discriminatório |
| **Responsabilidade** | Humano responsável por decisões críticas |
| **Privacidade** | Dados pessoais protegidos |
| **Segurança** | Modelos resistentes a ataques |

## Auditoria

| Prática | Periodicidade |
|---|---|
| Revisão de viés nos modelos | Trimestral |
| Teste de robustez | Semestral |
| Auditoria de decisões de IA | Trimestral |
| Revisão de consentimentos | Anual |
