# Interface Conversacional

## Propósito
Definir a interface de chat para o assistente virtual.

## Componentes

| Componente | Descrição |
|---|---|
| **Chat Box** | Janela de chat no canto inferior |
| **Input** | Campo de texto com envio |
| **Mensagens** | Balões de mensagens (utilizador/sistema) |
| **Sugestões** | Perguntas frequentes sugeridas |
| **Anexos** | Upload de documentos no chat |

## Comportamento

| Característica | Descrição |
|---|---|
| **Histórico** | Manter contexto da conversa |
| **Timeout** | 10 min de inactividade = nova conversa |
| **Escalamento** | Opção de falar com humano |
| **Feedback** | Polegar para cima/baixo em cada resposta |
| **Limitações** | Avisar que é IA e pode errar |
