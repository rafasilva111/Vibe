# Sumarização

## Propósito
Definir a funcionalidade de sumarização automática de processos e documentos.

## Casos de Uso

| Caso | Descrição |
|---|---|
| **Sumário de Processo** | Resumo do histórico e estado actual |
| **Sumário de Documento** | Resumo de documentos longos |
| **Sumário para Decisão** | Síntese para apoio ao dirigente |
| **Sumário para Cidadão** | Explicação em linguagem simples |

## Formato

| Elemento | Descrição |
|---|---|
| **Título** | Identificação do processo/documento |
| **Resumo** | 3-5 frases principais |
| **Pontos-chave** | Bullet points com informações essenciais |
| **Acções Necessárias** | Próximos passos (se aplicável) |
| **Confiança** | Indicador de confiança da sumarização |
