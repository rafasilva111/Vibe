# Estratégia LLM

## Propósito
Definir a estratégia de utilização de Large Language Models na plataforma.

## Modelos

| Modelo | Utilização | Custo |
|---|---|---|
| **GPT-4** | Sumarização, análise complexa | Alto |
| **Claude 3** | Assistente conversacional | Médio |
| **Modelo Open Source** | Classificação, extracção (futuro) | Baixo |

## Abordagem

- RAG (Retrieval-Augmented Generation) para respostas contextuais
- Fine-tuning apenas para tarefas muito específicas
- Prompt engineering com templates validados
- Human-in-the-loop para decisões críticas
