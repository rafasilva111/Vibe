# Assistente Virtual

## Propósito
Definir o assistente virtual para cidadãos e funcionários.

## Canais

| Canal | Público | Funcionalidades |
|---|---|---|
| **Chat Web** | Cidadão | FAQ, estado de processos, documentos |
| **Chat Funcionário** | Funcionário | Pesquisa, sugestões, sumarização |
| **Voice (futuro)** | Cidadão | Interacção por voz |

## Capacidades

| Capacidade | Descrição |
|---|---|
| **FAQ** | Respostas a perguntas frequentes |
| **Estado do Processo** | Consulta de estado e andamento |
| **Documentos** | Informação sobre documentos necessários |
| **Agendamento** | Marcação de atendimento |
| **Pesquisa** | Pesquisa na base de conhecimento |
