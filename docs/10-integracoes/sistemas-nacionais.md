# Sistemas Nacionais

## Propósito
Mapear as integrações com sistemas nacionais portugueses.

## Sistemas

| Sistema | Protocolo | Dados | Direção |
|---|---|---|---|
| **Autenticação.gov** | SAML/OIDC | Identidade + Cargo | Entrada |
| **Chave Móvel Digital** | OIDC | Identidade + Assinatura | Bidirecional |
| **eIDAS** | SAML/OIDC | Identidade UE | Entrada |
| **SIOE** | API REST | Organigrama | Entrada |
| **RNA** | API | Associações | Entrada |
| **INE** | API | Dados estatísticos | Entrada |
| **ePortugal** | API | Serviços partilhados | Bidirecional |
