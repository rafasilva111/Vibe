# Carteira Digital eIDAS

## Propósito
Integração com a carteira digital eIDAS para autenticação de cidadãos europeus.

## Protocolo

| Aspecto | Detalhe |
|---|---|
| **Protocolo** | OIDC / SAML |
| **Perfil** | Cidadão da UE |
| **Dados** | Nome, data de nascimento, nacionalidade |
| **Nível** | Nível 3/4 (eIDAS) |

## Atributos

| Atributo | Obrigatório |
|---|---|
| Nome completo | Sim |
| Data de nascimento | Sim |
| Nacionalidade | Sim |
| Número de identificação | Sim |
| Morada (opcional) | Não |
