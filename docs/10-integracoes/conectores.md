# Conectores

## Propósito
Definir os conectores para integração com sistemas externos.

## Tipos

| Tipo | Descrição | Exemplos |
|---|---|---|
| **REST** | API REST sobre HTTP | SIOE, RNA |
| **LDAP** | Diretório de utilizadores | AD, OpenLDAP |
| **SQL** | Base de dados relacional | RH, Financeiro |
| **Ficheiro** | Importação/exportação de ficheiros | CSV, XLSX |
| **SOAP** | Web service SOAP | Sistemas legados |
| **SFTP** | Transferência de ficheiros | Bancos |

## Monitorização

| Métrica | Descrição |
|---|---|
| **Estado** | Conectado / Desconectado / Erro |
| **Latência** | Tempo de resposta |
| **Taxa de Erro** | % de falhas |
| **Última Sincronização** | Data/hora da última operação |
