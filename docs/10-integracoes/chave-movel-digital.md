# Chave Móvel Digital

## Propósito
Integração com a Chave Móvel Digital para autenticação e assinatura de cidadãos.

## Protocolo

| Aspecto | Detalhe |
|---|---|
| **Protocolo** | OIDC (autenticação) / PDF (assinatura) |
| **Perfil** | Cidadão nacional |
| **Dados** | Nome, NIF, email, telemóvel |
| **Nível** | Nível 3/4 |

## Funcionalidades

| Funcionalidade | Descrição |
|---|---|
| **Login** | Autenticação com NIF + PIN |
| **Assinatura** | Assinatura digital de documentos |
| **Validação** | Validação de assinaturas CMD |
