# SMS

## Propósito
Definir a integração com serviços de SMS para notificações urgentes.

## Configuração

| Parâmetro | Detalhe |
|---|---|
| **Provider** | Twilio / Link Mobility |
| **Remetente** | Nome ou número curto |
| **Limite** | 1000 SMS/dia (configurável) |
| **Prioridade** | Notificações críticas (prazos, decisões) |

## Casos de Uso

| Tipo | Exemplo |
|---|---|
| **Notificação de Prazo** | "O seu processo P-2024-1234 expira em 5 dias." |
| **Decisão** | "O seu processo P-2024-1234 foi decidido. Consulte o portal." |
| **Alerta** | "Lembrete: tem agendamento amanhã às 10h na Junta." |
