# Email

## Propósito
Definir a integração com serviços de email para notificações.

## Configuração

| Parâmetro | Detalhe |
|---|---|
| **Provider** | AWS SES / SendGrid |
| **Remetente** | noreply@[junta].pt |
| **Autenticação** | SMTP / API |
| **Encriptação** | TLS 1.3 |
| **Limite** | 10.000 emails/dia (configurável) |

## Templates

- Templates HTML responsivos
| Personalização por inquilino
- Placeholders para dados dinâmicos
- Versão texto para acessibilidade
