# Análise Preditiva

## Propósito
Definir as capacidades de análise preditiva da plataforma.

## Modelos

| Modelo | Predição | Dados |
|---|---|---|
| **Duração do Processo** | Tempo estimado até conclusão | Histórico + tipo serviço |
| **Risco de Incumprimento** | Probabilidade de exceder prazo | Histórico + carga actual |
| **Probabilidade de Recurso** | Chance de decisão ser recorrida | Histórico + tipo decisão |
| **Afluência** | Volume esperado de pedidos | Sazonalidade + tendências |

## Métricas

| Métrica | Descrição |
|---|---|
| **Precisão** | % de predições correctas |
| **Recall** | % de eventos previstos |
| **MAE** | Erro médio absoluto (para regressão) |
| **RMSE** | Raiz do erro quadrático médio |
