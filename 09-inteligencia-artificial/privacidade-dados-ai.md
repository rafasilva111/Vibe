# Privacidade de Dados em AI

## Propósito
Definir as políticas de privacidade para utilização de IA.

## Princípios

| Princípio | Descrição |
|---|---|
| **Privacidade por Defeito** | Dados pessoais não enviados para LLMs externos |
| **Anonimização** | Dados anonimizados antes de processamento |
| **Consentimento** | Utilizador informado sobre uso de IA |
| **Transparência** | Identificação clara de respostas geradas por IA |

## Medidas

- Dados pessoais removidos antes de enviar para API LLM
- Utilização de modelos on-premise para dados sensíveis
- Logs de inferência sem dados pessoais
- Período de retenção de prompts reduzido
- Auditoria de acessos aos modelos
