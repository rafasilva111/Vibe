# Métricas de IA

## Propósito
Definir as métricas para avaliação dos sistemas de IA.

## Métricas por Componente

| Componente | Métricas |
|---|---|
| **Assistente Virtual** | Satisfação, taxa de resolução, escalamentos |
| **Sumarização** | Precisão, completude, legibilidade |
| **Classificação** | Precisão, recall, F1-score |
| **Recomendação** | Taxa de aceitação, precisão |
| **Extracção** | Precisão, recall de entidades |

## Monitorização

- Dashboards de performance de modelos
- Alertas para degradação de métricas
- Re-treino automático quando precisão < limiar
- A/B testing para novos modelos
